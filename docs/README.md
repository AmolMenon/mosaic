# Mosaic OS

Mosaic OS is an enterprise-grade AI research and intelligence platform designed for private equity, investment banking, and corporate strategy teams. It automates the extraction, formulation, and critique of strategic hypotheses using state-of-the-art Large Language Models.

## Architecture

- **Frontend:** Next.js 15 (App Router), React 19, TailwindCSS, Zustand, React Query
- **Backend:** Node.js 20, Express, Prisma, Zod
- **Database:** PostgreSQL 15
- **Orchestration:** Domain-Driven Design (DDD) workflow engine executing asynchronous extraction pipelines.
- **AI Providers:** OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet), Google Gemini.
