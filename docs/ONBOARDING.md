# Frictionless Onboarding

Mosaic OS aims for a zero-to-one Time-to-Value (TTV) of under 5 minutes.

## The First-Time User Experience (FTUX)

1. **Sign Up**: SSO integration with Okta, Google Workspace, or Microsoft Entra ID.
2. **Empty State Guidance**: Upon entering the dashboard, the user sees an interactive "Create your first Workspace" wizard, instead of a blank screen.
3. **Sample Data**: Users are given the option to run a demo pipeline using pre-loaded, anonymized Sample CIM data.
4. **Interactive Walkthrough**: When the IC Memo is generated, a guided tour highlights the citation feature, showing users how to trace a claim back to the source document.
