# Feedback & User Research Loop

To iterate rapidly during the Public Beta, we rely on tight feedback loops with early adopters.

## In-App Feedback
- **Bug Reporting**: Users can trigger a bug report anywhere in the app using `CMD+Shift+B` or via the help menu. Reports automatically capture the current state, Execution ID, and console logs, routing directly to the engineering team's Linear backlog.
- **NPS Surveys**: Triggered on the dashboard after a user successfully generates their third IC Memo.
- **Feature Requests**: Integrated Canny/Featurebase board accessible via the dashboard for users to upvote missing capabilities.

## User Interviews
- **Beta Cohort Cadence**: The Product team will conduct 30-minute qualitative interviews with 5 active users per week.
- **Goal**: Understand where the LLM insights diverge from the user's expectations, and identify UX friction in the document ingestion flow.

## Support SLAs
- **Beta Users**: Best-effort email support within 24 hours.
- **Enterprise Pilots**: Dedicated shared Slack channel with engineering access.
